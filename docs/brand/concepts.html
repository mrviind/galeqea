QE Agent — logo concepts, round 2

Round 1's “Gate” mark failed: a stem rising above the crossbar reads as a crucifix, not a T. These three keep the T unambiguous. All monochrome — in a test tool colour carries meaning (pass/fail), so the brand must not compete with it.

A2 · Split stem
An unmistakable T with a break in the stem — the gate every change passes through. One idea, three rectangles, no curves.
